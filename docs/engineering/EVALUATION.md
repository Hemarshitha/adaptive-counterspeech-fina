# Evaluation protocol (not results)

Academic authority: proposal p.2–3. No collected ratings, trained model, accuracy, human efficacy or benchmark result is asserted.

Use held-out, licensed source data with provenance, language/script and source/conversation grouping. Resolve multilingual CONAN versus multi-target CONAN coverage before collection. Keep synthetic dialogues in a distinct partition; do not let template-related or same-thread examples cross splits. Do not import previous-semester generated data.

Compare `single_shot`, `no_simulation`, `no_history` and `full` under recorded model, prompt version, inference parameters and held-out examples. The one-shot baseline is newly implemented from the high-level Saha et al. (2024) zero-shot paradigm cited by proposal [1]; exact paper prompt replication remains unverified. Report all attempted cases and failures, not just successful runs. API stage assessments are model estimates, not independent evaluation.

Evaluate toxicity/safety, relevance, argument strength, counterspeech quality, fluency, language/script preservation, predicted de-escalation, actual multi-turn consistency, latency and tokens. Add external multilingual toxicity/quality tools only after validating language applicability and licensing. Monetary cost stays null until provider pricing is explicitly supplied. Never interpret reaction probabilities as calibrated without a separately labeled calibration set.

Human study target: approximately **100–150 examples**, per the proposal, with balanced language/target coverage and paired baseline/full comparisons. Predefine number of raters, sample-size rationale and institution-specific ethics/consent process with the guide. Randomize and blind response order; hide model, strategy, mode and predicted reactions. Use 1–5 anchored scales: safety, relevance, respectful disagreement, argument strength, language naturalness and expected de-escalation; allow cannot-assess. Expected de-escalation remains a judgment, not an observed behavioral outcome. Record pseudonymous rater ID, item ID, order seed, consent/provenance, missingness and language competence. Compute inter-rater agreement appropriate to ordinal ratings and paired bootstrap confidence intervals grouped by conversation. Do not fill any rating automatically.

For simulated multi-turn dialogues, explicitly label every generated turn `synthetic`, record generating model/config and split group, and collect separate actual human validation. Such dialogues never enter observed production conversation history. A separate rollout/annotation workflow is a later milestone. Publication artifacts must include raw accepted/failed run manifests, rubric, policy/config, prompt versions, split definitions, validated dataset documentation and genuine study outputs.
